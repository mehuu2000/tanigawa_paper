# 進捗: creator からイニシャルを削除した再実験

## 目的

`progress5/改修方針_イニシャル.md` に基づき、Solr の `creator` から英語著者のイニシャル派生表記を削除し、閾値再取得とシステム再評価を行う。

この実験は、パーフェクト条件の後に行う比較実験である。

確認したいこと:

- イニシャル派生表記がない場合に、RC / MC がどの程度影響を受けるか。
- 参考文献文字列側に存在するイニシャル表記が候補文献側にない場合、RC が低下することを確認できるか。
- パーフェクト条件との差分を説明できるか。

備考:

- RC はイニシャル削除の影響を受けており、予備実験用正例 2103件のうち 9件はスコアが 1.0 未満になった。
- 代表例として、`CLANUWAT, T.，LAMB, A.，KITAMOTO, A.` や `Simon, G.` のような英語著者イニシャル表記を含む参考文献では、候補文献側 `creator` から `T` / `A` / `G` などの派生イニシャルを削除したため、RC が低下した。
- ただし、負例側にも RC スコア 1.0 のものが 3件あり、さらに 0.98 台の高スコア負例も存在した。
- 閾値決定は正例最小値ではなく、`roc_curve` の候補閾値ごとに F1 を計算し、F1 が最大になる閾値を採用している。
- そのため、閾値を 1.0 未満に下げて 9件の正例を拾うより、閾値 1.0 のままにして高スコア負例の誤検出を抑える方が F1 が高くなり、RC の Best Threshold は 1.0 になった。
- MC は RC の低下を受け、正例最小値に相当する `0.9887005649717513` が Best Threshold になった。

## パーフェクト条件との差分

### 正例

- BM25 はパーフェクト条件より正常検出が 19件増加し、検出漏れが 19件減少した。誤検出は 3件で変化なし。

- RC はパーフェクト条件より正常検出が 8件減少し、検出漏れが 8件増加した。
- CC と MC はパーフェクト条件と同じく、正例 2529件すべて正常検出であった。

### 負例

- BM25 はパーフェクト条件より True negative が 15件増加し、False positive が 15件減少した。
- BM25正規化はパーフェクト条件より True negative が 63件増加し、False positive が 63件減少した。
- RC / CC / MC はパーフェクト条件から変化なし。

### 閾値

- BM25 は `40.903572` から `40.988663` に上昇した。
- BM25正規化は `1.7382530952380952` から `1.7602185714285714` に上昇した。
- RC と CC はどちらも `1.0` のままで変化なし。
- MC は `1.0` から `0.9887005649717513` に低下した。

### 考察

- イニシャル削除により、`Nontachai, T.` や `Adnan, A.` のような英語著者イニシャル表記を含む正例で RC が低下し、8件の検出漏れが発生した。

- CC は `creator` ではなく `first_author` を中心に候補文献側フィールドの包含率を見るため、今回の `creator` からのイニシャル削除の直接影響は出なかった。
- BM25 / BM25正規化は、`creator` からイニシャル派生トークンが減ったことで検索スコア分布が変化し、パーフェクト条件より正例・負例ともに改善した。
