# 改修方針: creator からイニシャルを削除した再実験

## 背景

`progress5/改修方針_パーフェクト.md` では、以下の改修を行う予定である。

- Solr の `first_author` を `last_name` のみに戻す。
- `wakati.py` の先頭数字削除処理を削除する。

この改修により、想定している範囲では RC / CC / MC の検出漏れが 0 になる可能性が高い。

理由は、評価対象の正例データは DB に存在する文献を元に作成しており、Solr に登録されているメタデータとほぼ同じ情報から参考文献文字列を生成しているためである。

ただし、この状態をそのまま研究結果として強く主張する意味は薄い。

なぜなら、現在の Solr 登録処理では、元データに存在しない派生情報も追加しているためである。

特に `creator` では、英語著者の `first_name` からイニシャルを生成して登録している。

これは検索・照合を安定させるための独自拡張であり、JaLC 元データに最初から存在する情報ではない。

一般的に最初に実装するシステムでは、このようなイニシャル派生表記を登録しない可能性が高い。

そのため、次の実験では `creator` からイニシャル生成を削除し、元データに近い登録状態にした場合の評価を確認する。

## 目的

`creator` に追加している英語著者のイニシャル由来トークンを削除し、再度閾値取得・再評価を行う。

この実験により、以下を確認する。

- イニシャルを追加しない一般的な登録方式では、英語著者を含む参考文献で RC / MC がどの程度影響を受けるか。
- RC は参考文献文字列側のトークンが候補文献側にどれだけ含まれるかを見るため、候補文献側に登録されていない著者表記があるとスコアが下がることを確認する。
- 元データに存在しない派生表記を追加することの効果と、その有無による評価差を説明できるようにする。

## 改修内容

### Solr 登録側: `creator` のイニシャル生成を削除

対象:

- `4プログラム/jalc-to-solr.ipynb`

現在の `get_creator()` では、英語著者の `first_name` を分割し、その各要素のイニシャル順列を `creator` に追加している。

現在の処理:

```python
if regex.search(first_name):
    split_name = re.split(r"[,\\.\\s\\-\\(\\)]", first_name)
    names = [n for n in split_name if n]
    creator_list += names
    # recallの計算用に全てのイニシャルの順列の組み合わせ（2個まで）を用意しておく
    initials = [e[0].upper() for e in names if re.search(r"[a-zA-Z]", e[0])]
    for r in range(1, 3):
        for perm in permutations(initials, r):
            creator_list.append("".join(perm))
```

今回の改修では、イニシャル順列を追加する以下の部分を削除する。

```python
initials = [e[0].upper() for e in names if re.search(r"[a-zA-Z]", e[0])]
for r in range(1, 3):
    for perm in permutations(initials, r):
        creator_list.append("".join(perm))
```

一方で、以下は残す。

- `last_name`
- `first_name`
- `first_name` を分割した各要素
- 英語著者の `last_name first_name`
- 日本語著者の `last_name + first_name`
- 空白のみ著者の除外

## 削除対象と残す対象

### 削除するもの

英語著者の `first_name` 由来のイニシャル。

例:

```text
first_name = TITHIPONGTRAKUL
削除対象 = T

first_name = John Michael
削除対象 = J, M, JM, MJ
```

### 残すもの

例:

```text
last_name = Nontachai
first_name = TITHIPONGTRAKUL
```

残す `creator`:

```text
Nontachai
TITHIPONGTRAKUL
Nontachai TITHIPONGTRAKUL
```

削除する `creator`:

```text
T
```

## 実験の位置づけ

この実験は、パーフェクト条件の後に行う比較実験である。

パーフェクト条件:

- DB に存在するデータを元に正例を作成。
- Solr 側にも照合に必要な派生表記を十分に持たせる。
- 想定範囲では RC / CC / MC の検出漏れ 0 を目指す。

イニシャル削除条件:

- 元データに存在しないイニシャル派生表記を削除。
- より自然な初期実装に近い登録状態にする。
- 英語著者のイニシャル表記を含む参考文献で、RC / MC が落ちるか確認する。

## 想定する影響

### RC

RC は参考文献文字列側のトークンが候補文献側にどれだけ含まれるかを見る。

そのため、参考文献文字列側に英語著者のイニシャルが含まれ、候補文献側 `creator` にそのイニシャルが存在しない場合、RC は低下する。

### CC

CC は `first_author` を見るが、パーフェクト方針で `first_author` は `last_name` のみに戻す。

そのため、今回のイニシャル削除は主に `creator` に効く変更であり、CC への直接影響は限定的と考えられる。

### MC

MC は RC と CC の合成であるため、RC が低下した場合に MC も低下する可能性がある。
