今回の主な変更点:

- Solr 登録時の英語著者表記を補正。
- Solr 登録時の `title | subtitle` を `title subtitle` に変更。

- 正例データ作成時の互換漢字による日本語判定漏れを補正。
- 負例データ内の LSJ 英語著者表記を補正。

### config.py 反映

反映日時:

反映内容:

```python
SOLR_DOC_COUNT = 3617024
SOLR_CORE_NAME = "jalc"
BM25_THRESHOLD = 40.9035

RC_THRESHOLD = 0.9846
CC_THRESHOLD = 0.9583
MC_THRESHOLD = 0.9663
```

備考:

- 現在の閾値決定では、正例スコアと負例スコアを結合し、`roc_curve` で得た候補閾値ごとに F1 を計算する。その中で F1 が最大になる閾値を `Best Threshold` として採用している。
- そのため、実質的には「正例側で低いスコアのデータ」と「負例側で高いスコアのデータ」の境界が閾値に強く影響する。
- 今回、Solr 登録データや予備実験用データは変更されているが、CC / MC では境界になるスコアが前回と変わらなかった。
- そのため、少数第五位以下を切り捨てた CC / MC の閾値は前回と同じ値になった。
- 確認した境界スコアは以下の通り。

```text
CC:
正例の最小値 = 0.9583333333333334
負例の最大値 = 0.9375
Best Threshold = 0.9583333333333334

MC:
正例の最小値 = 0.9663865546218489
負例の最大値 = 0.9398075632132468
Best Threshold = 0.9663865546218489
```

- つまり、データ全体は変わっているが、CC / MC の閾値を決める境界データが変わらなかったため、閾値も変わらなかったと考えられる。
