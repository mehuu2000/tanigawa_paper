# 進捗: データ登録・データ作成の改修

## 2026-07-04

### Solr 登録データ作成処理の修正

対象ファイル:

- `4プログラム/jalc-to-solr.ipynb`

修正目的:

- Solr に登録する著者表記と、参考文献文字列側の著者表記の不一致を減らす。
- `subtitle` がある文献で、Solr 側と参考文献文字列側のタイトル表記を揃える。

### 修正内容

#### 1. `creator` に英語著者の空白ありフルネームを追加

修正前:

```python
creator_list += last_name.split()
first_name = name.get("first_name","")
creator_list += first_name.split()
```

修正後:

```python
creator_list += last_name.split()
first_name = name.get("first_name","")
creator_list += first_name.split()
# 英語著者などの空白ありフルネームを追加
if last_name and first_name and (regex.search(first_name) and regex.search(last_name)):
    creator_list.append(last_name + " " + first_name)
```

これにより、英語著者について `last_name`、`first_name` に加えて、`last_name first_name` も `creator` に登録される。

例:

```text
Nontachai
TITHIPONGTRAKUL
Nontachai TITHIPONGTRAKUL
```

#### 2. `first_author` に英語筆頭著者の `first_name` と空白ありフルネームを追加

修正前:

```python
if last_name:
    fa_names.append(last_name)
else:
    fa_names.append(first_name)
```

修正後:

```python
if last_name:
    fa_names.append(last_name)
    if first_name and (regex.search(first_name) and regex.search(last_name)):
        fa_names.append(first_name)
        fa_names.append(last_name + " " + first_name)
else:
    fa_names.append(first_name)
```

これにより、英語筆頭著者について `last_name` だけでなく、`first_name` と `last_name first_name` も `first_author` に登録される。

例:

```text
Nontachai
TITHIPONGTRAKUL
Nontachai TITHIPONGTRAKUL
```

#### 3. `title | subtitle` を `title subtitle` に変更

修正前:

```python
title_list.append(t.get("title"))
if (subtitle := t.get("subtitle")) is not None:
    title_list.append(t.get("title") + " | " + subtitle)
```

修正後:

```python
title_list.append(t.get("title"))
if (subtitle := t.get("subtitle")) is not None:
    title_list.append(t.get("title") + " " + subtitle)
```

これにより、`subtitle` がある文献では、Solr 側にも参考文献文字列作成側と同じ `title subtitle` 表記が登録される。

`title` 単体の登録は維持している。

### 確認結果

`4プログラム/jalc-to-solr.ipynb` について、以下を確認済み。

- `creator` に `last_name + " " + first_name` を追加する処理が入っている。
- `first_author` に `first_name` と `last_name + " " + first_name` を追加する処理が入っている。
- `title + " | " + subtitle` は残っていない。
- `title + " " + subtitle` に変更されている。
