# 改善方針_F05

## 最終目標
- 現在の MC を `RC` と `CC` の調和平均 (`F1`) から `F0.5` に変更する。
- `F0.5` に変更した MC を用いて、新しい `MC_THRESHOLD` を再取得する。
- 取得した `MC_THRESHOLD` を `config.py` に反映し、その状態で MC の再評価を行う。

## 前提
- 今回の対象は MC のみである。
- `RC` `CC` `BM25` `BM25正規化` の定義や閾値は変更しない。
- MC の計算には `RC` と `CC` のスコアが必要だが、それらは MC セル内で候補文献ごとに再計算する。
- そのため、RC / CC 単体のスコア算出セルや閾値決定セルの結果は、MC の閾値再取得には使わない。

## MC の定義
- 変更前:
  - `MC = 2RC・CC / (RC + CC)`
- 変更後:
  - `MC = (1 + 0.5^2)RC・CC / (0.5^2・CC + RC)`
  - すなわち `MC = 1.25RC・CC / (0.25CC + RC)`

## 想定手順

### Step1, MC の式を F0.5 に変更する
- 対象 notebook
  - `4プログラム/preliminary_experiment.ipynb`
  - `4プログラム/evaluation_experiment.ipynb`
  - `4プログラム/execute_proposed_method.ipynb`
- 方針
  - `calc_mc` の式のみを `F1` から `F0.5` に置き換える。
  - notebook 内の MC 説明文も `F0.5` の式に合わせて更新する。
  - MC 以外の手法のロジックは変更しない。

### Step2, MC の閾値を再取得する
- 対象 notebook
  - `4プログラム/preliminary_experiment.ipynb`
- 使用データ
  - 正例データ: `5-1予備実験用データ/5-1-1参考文献文字列_誤植なし（実在）/positive_reference_*_pre_none_typo.txt`
  - 負例データ: `5-1予備実験用データ/5-1-2参考文献文字列（架空）/negative_reference_*_pre.txt`
- 方針
  - Solr 上位 10 件の候補に対して、MC セル内で `RC` と `CC` を計算する。
  - その `RC` と `CC` から `MC(F0.5)` を計算し、候補 10 件の最大値を各参考文献文字列のスコアとして採用する。
  - 正例・負例の MC スコア一覧を用いて、`F1` が最大となる `MC_THRESHOLD` を取得する。
- 実行対象
  - MC スコア作成と MC 閾値決定に必要なセルのみを実行する。
  - RC / CC / BM25 / BM25正規化の閾値結果は今回の更新対象ではない。

### Step3, config.py の MC_THRESHOLD を更新する
- 対象ファイル
  - `4プログラム/config.py`
- 方針
  - `Step2` で得られた `MC_THRESHOLD` を `Current values` に反映する。
  - 直前の `MC_THRESHOLD` は、これまでと同様にコメントブロックとして残す。
  - `BM25_THRESHOLD` `BM25_NORMALIZED_THRESHOLD` `RC_THRESHOLD` `CC_THRESHOLD` は変更しない。

### Step4, F0.5 に変更した MC で再評価する
- 対象 notebook
  - `4プログラム/evaluation_experiment.ipynb`
- 使用データ
  - 正例データ:
    - `5-2評価実験用データ/5-2-1参考文献文字列_誤植なし_Crossrefなし（実在）/positive_reference_ipsj_eval_none_typo_crossref.txt`
    - `5-2評価実験用データ/5-2-1参考文献文字列_誤植なし_Crossrefなし（実在）/positive_reference_jsai_eval_none_typo_crossref.txt`
    - `5-2評価実験用データ/5-2-1参考文献文字列_誤植なし_Crossrefなし（実在）/positive_reference_lsj_eval_none_typo_crossref.txt`
  - 正例 DOI:
    - `5-2評価実験用データ/5-2-1参考文献文字列_誤植なし_Crossrefなし（実在）/doi_list.txt`
  - 負例データ:
    - `5-2評価実験用データ/5-2-2参考文献文字列（架空）/negative_reference_*_eval.txt`
- 方針
  - `MC` のみ再評価する。
  - 正例は `case1`, `case2+4`, `case3` で整理する。
  - 負例は `False positive` で整理する。

### Step5, 結果の整理と記録
- 対象ドキュメント
  - `9その他/濱田修正ドキュメント/progress/progress3/進捗_F05.md`
- 方針
  - MC の式変更、MC 閾値、MC の正例・負例結果、3 スタイル合算統計を記録する。
  - 必要に応じて、従来の `MC(F1)` 結果との差分も補足する。
